# 100xDevs Landing Page Clone

A responsive landing page clone of [100xDevs](https://100xdevs.com/) built using HTML and Tailwind CSS.

This project was made for learning and practice. It recreates the look and feel of the original homepage with sections like the hero area, stats, course cards, podcasts, community section, FAQs, and contact form.

## Preview

Open `index.html` in your browser to view the page.

## Tech Stack

- HTML
- Tailwind CSS CDN
- Vanilla JavaScript

## Features

- Responsive navbar
- Mobile menu
- Hero section
- Stats section
- Skills/features grid
- Featured cohorts section
- Podcast cards
- Community section
- FAQ accordion
- Contact form UI
- Footer

How to Run
Download or clone this repository.
Make sure the assets folder is in the same directory as index.html.
Open index.html in your browser.
No installation is required because Tailwind is loaded using CDN.
